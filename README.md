# Shape Match

Jogo de memória desenvolvido em Python com Pygame como forma de aprender mais sobre desenvolvimento.

O objetivo é memorizar uma sequência de formas geométricas e repetir a sequência corretamente.

## Funcionalidades

- Sequências aleatórias
- Sistema de rodadas
- Pontuação
- Vidas
- Feedback de acerto e erro

## Tecnologias

- Python
- Pygame
